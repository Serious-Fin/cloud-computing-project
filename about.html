About

A mock blog, on purpose.

The Deploy Log is a small fake publication about cloud computing. It exists to demonstrate what a static site deploy looks like end to end.

How it is built

No build step

Every page is a plain HTML file. Styles live in one CSS document, and a single small script handles the theme toggle, the reading progress bar and the post filter. There is nothing to compile.

No server, no database

The browser does all the work. Post filtering happens in JavaScript against the cards already on the page, so the site needs no backend and no query language.

Ready for a CDN

Because it is just files, it can be published by dragging the folder onto a host or by connecting this repository. Publish the root directory and you are done.

What it is not

  • Not a content management system — posts are edited as HTML.
  • Not search-optimised beyond basic meta tags.
  • Not connected to analytics or comments.

Making it yours

Copy a file in posts/, change the title, date and body, then add a matching card to index.html. Update the data-tags attribute if you want the new post to appear under a topic filter. 

<li class="post-card"
    data-tags="cloud"
    data-title="my new post"
    data-excerpt="a short summary for the search box">
  <a href="posts/my-new-post.html">…</a>
</li>
